# Code of Conduct

## Our commitment

We want participation in this project to be respectful and constructive,
regardless of experience level, background, or identity.

## Expected behavior

- Be respectful and assume good faith.
- Keep discussions technical and on topic.
- Give actionable feedback and accept feedback gracefully.
- Respect privacy: do not publish other people's IP addresses, proxy
  credentials, or personal data.

## Unacceptable behavior

- Harassment, discrimination, personal attacks, or threats.
- Publishing private information without permission.
- Deliberately disruptive behavior, spam, or bad-faith reports.
- Encouraging or assisting abuse of the public instances.

## Enforcement

Maintainers may edit or remove contributions, close issues or pull requests,
and block participation when this code is violated. Report concerns to the
maintainer via GitHub ([@nechel12](https://github.com/nechel12)); for sensitive
reports, ask for a private channel first.

This code applies in project spaces and when representing the project
elsewhere.
